# engineering-paved-path

Shared, framework-level engineering-practice skills for any TypeScript web
app repository. No dependencies — every other plugin in this marketplace
builds on this one.

## Skills

`react-best-practices`, `next-best-practices`, `fastify-best-practices`,
`drizzle-orm-patterns`, `postgresql-table-design`, `zod`,
`typescript-expert`, `security`, `onion-architecture`, `mermaid-diagram`,
`frontend-ui-architecture`, `react-testing-library`.

Each skill triggers on its own `SKILL.md` description — see that file for
exactly when Claude Code should load it. `onion-architecture` and
`frontend-ui-architecture` are written to be applied against *any* target
repository's own module layout and architecture docs, not a fixed set of
package names — read each skill's own "Project-local grounding"/"Step
zero"-style guidance before applying it.

## Install

```
/plugin install engineering-paved-path@dev-digest-ai-marketplace
```
